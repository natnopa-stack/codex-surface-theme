# Codex Surface Theme 1.15.9 发布说明

面向 Windows Codex 桌面版的非官方社区主题，沿用仓库现有 MIT 许可证。

## 当前功能

- 中性 Canvas 与独立 Surface 面板，小圆角、细边框和克制阴影；仅在深色下启用 Surface；浅色使用原版，切回深色恢复偏好。
- Composer 彩条独立开关，提供细流光边、星光粒子和自定义色，保留原生 `+`、模型、语音和发送操作。
- 左侧项目单列树、项目色主干、扁平线程分支、八种配色和八种 Tabler Outline 项目图标。
- 四种状态灯：Rider 游侠红扫描、紫白 Plasma 导通呼吸、绿色 ECG 脉冲和 VOX 动态示波。
- Assistant 状态条、左上角 Online Core 和 LIVE ACTIVITY 使用独立开关；LIVE ACTIVITY 可单独选择强调色。
- LIVE ACTIVITY 只显示可观察到的任务、工具和 Agent 状态，不伪造未知百分比；新版侧栏下以紧凑卡片独立占用目录底部空间，随目录宽度适配，避免遮挡项目、额度和头像。
- Composer Context 圆环支持五种配色；导航轨道底部独立额度位支持 `隐藏 / 状态 / 精确`，可点击展开精确面板。

- 新版外观控件独立成区、窄窗口换行；紧凑项目间距、自定义消息颜色和原生上下文圆环适配保留。
- 游侠活动周期 3.2 秒，待机 5.6 秒。
- 本版本不含浅色三维光效、浅色皮肤控件或私人预设。

动态效果见 [SHOWCASE.md](SHOWCASE.md)。

## 性能与本地安全

- 过滤高频流式文字变化、去重组件刷新并避免无变化的 DOM 写入，解决主题观察器自触发和组件互相拖慢造成的卡顿。
- VOX 改为页面内 Worker + OffscreenCanvas 绘制，文字输出占用主线程时仍可推进电流；不支持时回退到原有主线程绘制。隐藏时停绘，卸载或重新注入时终止 Worker，无外部服务或新依赖。
- 思考／活动状态以连续噪声改变波峰位置、宽度、能量和细节，避免机械重复；待机外观与运动参数保持。
- VOX 复用单一 DPR 自适应循环，活动最高 30fps、待机最高 15fps，不可见时停止绘制；相位连续推进，保留帧率调度余数，避免延迟后突然补跳。
- 状态卡片内部更新不会重刷整批项目样式。
- 主题通过 `127.0.0.1` 上的一次性本地 CDP 连接工作，不修改官方安装文件；注入完成后脚本退出，不保留后台服务或 watcher。
- 不上传项目、对话、状态或额度数据，不调用模型/API、不发送提示词，因此不额外消耗模型 Token。
- 组件只读取 Codex 当前渲染器已有状态和本地查询缓存；偏好保存在本地 `localStorage`。
- 公开包不包含用户名、本地绝对路径、端口/PID、任务/线程 ID、运行时状态、恢复快照或私有截图。

> 当前设备的 17 秒实际输出采样中，VOX 绘制 510 帧，最大绘制间隔约 50ms；600ms 主线程阻塞测试期间仍绘制 18 帧。此结果针对 VOX 动画，不能保证 Codex 官方文字渲染和所有机器都无停顿。

## 安装与更新后恢复

1. 完全退出 Codex，包括托盘进程。
2. 运行 `LAUNCH-CODEX-THEMED.cmd`。
3. 使用 `THEME-STATUS.cmd` 做只读状态检查；需要移除时运行 `REMOVE-THEME.cmd`。

Codex 更新后，如果主题没有加载，请完全退出更新器启动的 Codex，再从 `LAUNCH-CODEX-THEMED.cmd` 启动。详细说明见 [INSTALL.md](INSTALL.md)、[COMPATIBILITY.md](COMPATIBILITY.md) 和 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

Launcher 检测到无主题端点的运行中 Codex 时只会安全退出，不会关闭、强制结束或自动重启进程，避免打断活动任务。
